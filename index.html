Teori Dasar Percabangan (IF - ELSE IF - ELSE)

Dalam struktur pemrograman komputer, Logika Kondisional (Percabangan) memungkinkan program mengambil keputusan berdasarkan kriteria tertentu.

if (kondisi_A) {
  // Dijalankan jika kondisi_A BENAR (True)
} else if (kondisi_B) {
  // Dijalankan jika kondisi_A SALAH dan kondisi_B BENAR
} else {
  // Dijalankan jika SEMUA kondisi di atas SALAH
}

Prinsip Penting: Urutan evaluasi dimulai dari paling atas. Ketika sebuah kondisi bernilai True, kode di dalam blok tersebut akan dieksekusi, dan sistem langsung keluar dari seluruh struktur IF-ELSE.

Langkah Praktikum Simulasi

  1. Klik tombol "Aktifkan Kamera" untuk mengizinkan webcam atau gunakan "Mode Slider" untuk simulasi manual.
  2. Amati perubahan nilai var jarak saat Anda mendekatkan atau menjauhkan tangan dari kamera/slider.
  3. Perhatikan sorotan warna pada Logic Editor (Panel Kiri) saat kondisi IF, ELSE IF, atau ELSE terpenuhi.
  4. Coba ubah angka pada kotak input Threshold (150 dan 350) untuk mengubah batas keputusan program secara langsung.
