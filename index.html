BAB 1 • Dasar Keahlian 2 (Media Peralatan Jaringan)

Mengenal Media Jaringan: Wireless Router (AP), Switch/Hub & Client

Pada tahap awal, siswa mempelajari perangkat penghubung jaringan nirkabel (Wireless Router WRT300N) untuk menghubungkan PC dan Laptop dalam satu jaringan lokal menggunakan layanan DHCP Server, pengaturan SSID, keamanan WPA2-Personal, serta penggantian modul fisik WPC300N pada Laptop-PT.

Alur Konfigurasi Packet Tracer

1. Topologi Perangkat

Siapkan 1 PC (kabel ke port Ethernet WRT300N), 1 Wireless Router WRT300N, dan 4 Laptop-PT.

2. Modul Fisik Laptop (WPC300N)

Matikan tombol power Laptop → lepas modul LAN FastEthernet → pasang modul Wi-Fi WPC300N → nyalakan kembali.

3. GUI WRT300N (DHCP & Security)

Atur IP Router (192.168.0.1), aktifkan DHCP Server, ubah SSID pada Basic Wireless Settings, dan pasang sandi WPA-Personal (AES).

BAB 3 • Media Jaringan Kabel & Layanan Server

Konfigurasi Multi-Web Server, DHCP & DNS Server

Memahami fungsi komputer Server dan Switch Hub dalam melayani banyak alamat website lokal. DNS Server menerjemahkan nama domain (misal smkn2lamongan.sch.id atau wibal.net) menjadi alamat IP masing-masing Web Server agar mudah diakses melalui Web Browser client.

Langkah Praktikum 3 Server

1. Pengalamatan IP Server

Server0 (192.168.1.1), Server1 (192.168.1.2), Server2 (192.168.1.3) terhubung ke Switch 2950-24.

2. Layanan DHCP pada Server0

Atur Start IP Address mulai digit belakang 50, Maximum Users 50, dan DNS Server 192.168.1.1.

3. DNS A-Record Mapping

Aktifkan Service DNS pada Server0, lalu daftarkan nama domain untuk setiap IP Web Server dan klik Add.

BAB 4 • Fungsi Server sebagai Layanan Berkirim Pesan

Konfigurasi Mail Server (SMTP & POP3) pada Cisco Packet Tracer

Server dapat difungsikan sebagai pusat pertukaran surat elektronik internal menggunakan protokol SMTP (mengirim pesan) dan POP3 (menerima pesan) dengan domain lokal seperti wibal.net.

Tahapan Setup Email

1. Aktivasi DNS & Email Service

Pastikan domain wibal.net sudah terdaftar di DNS (192.168.1.1). Buka tab Services > EMAIL, aktifkan SMTP & POP3, isi Domain Name wibal.net lalu klik Set.

2. Pembuatan Akun User

Tambahkan akun user1 dan user2 beserta password masing-masing melalui tombol (+).

3. Configure Mail Client

Pada PC0 & PC1, isi Incoming dan Outgoing Mail Server dengan wibal.net, lalu uji dengan Compose dan Receive.
